# Security policy

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting for this repository. Include the affected path,
revision, reproduction, impact, and the smallest safe remediation you know.

Never include live credentials, private prompts, customer data, or unrestricted
telemetry in a report. Use synthetic evidence and redact operational IDs.

Static analysis is one layer of defense. Review a skill's instructions, source,
permissions, tools, network effects, and update path before installation.
